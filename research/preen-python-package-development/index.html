📦preen: Python Package Development ChecksRelated: py-canon: shared Python package standards; r-canon: shared R package standards
preen helps Python packages adopt and maintain the py-canon development standard. Its command-line tools scaffold repositories, update shared templates, check conformance, apply fixes, and guide tag-based releases.
