Which Women Are Missing? Adult Sex Ratio By Last Name
With Suriyan Laohaprapanon.
We use Indian electoral-roll records for more than 35 million people to estimate adult sex ratios by surname. The analysis describes variation that state-level averages can obscure, using recorded electoral-roll gender labels.
